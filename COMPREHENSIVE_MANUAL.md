# Deepfake Audio Detection Pipeline - Comprehensive Manual

## 1. System Overview
This repository contains a modular, end-to-end pipeline for generating and detecting deepfake audio. It is designed for **reproducibility**, **strict data separation (disjointness)**, and **security**.

### Key Modules
*   **Pipeline (`pipeline/`)**: Core logic for data generation, feature extraction, and model training.
    *   `data_gen/`: Chunking and splitting audio (Mozilla Common Voice).
    *   `synthesizer/`: TTS and Voice Conversion (Edge-TTS, RVC).
    *   `effects/`: Audio augmentations (background noise, encoding quality).
    *   `features/`: Feature extractors (CQT, LFCC, Mel-Spec).
*   **Utilities (`utilities/`)**: Helper scripts for model management and verification.
    *   `huggingface_hub.py` & `pth_security.py`: Robust, secure model downloading.
    *   `verify_leakage.py`: Critical script to prove train/test data separation.

## 2. User Manual: How to Run

### A. Environment Setup
1.  **Install Base Dependencies**:
    ```bash
    pip install -r requirements.txt
    ```
2.  **Install Security Tools**:
    ```bash
    pip install fickling
    ```

### B. Setup & Downloads
Before generating data, you must download the necessary assets.

*   **Download RVC Voice Models**:
    *   Downloads verified models (Ariana, Biden, etc.) from the registry.
    *   *Note:* If on Python 3.14+, use the `unquarantine` script afterwards.
    ```bash
    python utilities/download_rvc_models.py
    ```

*   **Restore Models (Python 3.14+ Only)**:
    *   If `fickling` fails due to version incompatibility, use this to bypass and restore standard models.
    ```powershell
    $env:ALLOW_UNSAFE_PTH="1"; python utilities/unquarantine_and_scan.py
    ```

*   **Download Textures (Noise/Impulses)**:
    ```bash
    python utilities/download_textures.py
    ```

### C. Running the Pipeline
The main entry point is `run_pipeline.py`. It reads `config.yaml`.

*   **Standard Run (TTS + Augmentation)**:
    ```bash
    python run_pipeline.py
    ```

*   **Enable/Disable Components**:
    Edit `config.yaml`:
    ```yaml
    enable_vc: true        # Enable Voice Conversion (RVC)
    enable_features: true  # Extract CQT/LFCC features
    ```

### D. Verification (Critical)
Always verify your dataset after generation to ensure no voice leakage occurred.

*   **Verify Disjointness**:
    ```bash
    python utilities/verify_leakage.py datasets/your_output_folder
    ```
    *Output should show [PASS] for all checks (Speaker ID overlap, RVC model overlap, etc).*

## 3. Configuration Guide (`config.yaml`)

*   **`voice_pools`**: Defines which TTS voices go to `train`, `test`, and `val`. **Never mix them.**
*   **`vc_pools`**: Defines RVC models for the splits.
*   **`augmentation`**: Controls probability of background noise, reverb, and MP3 compression.
