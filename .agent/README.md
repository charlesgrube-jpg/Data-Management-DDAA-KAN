# Antigravity Agent Configuration

This directory contains workflows and configuration for the Antigravity AI coding assistant.

## Workflows

Workflows are step-by-step guides for common development tasks. You can reference them using slash commands:

- `/setup-environment` - Setup Python environment and dependencies
- `/download-mozilla` - Download Mozilla Common Voice dataset
- `/run-pipeline` - Run the main TTS deepfake detection pipeline
- `/test-pipeline-component` - Test individual pipeline components  
- `/validate-output` - Validate pipeline output and dataset quality

## Usage

Simply mention a workflow (e.g., "run /setup-environment") and the agent will execute the steps automatically.
